# AnixArtix

Независимый клиент для Windows 10/11 x64 на Tauri 2 + Rust, с интерфейсом Svelte. Основан на [AniXFlow](https://github.com/MjKey/AniXFlow), с новым интерфейсом и комнатами совместного просмотра. Не является официальным приложением Anixart.

## Что изменено

- Новый интерфейс каталога, подписанная боковая навигация, тёмная и светлая темы, собственный логотип.
- Комнаты просмотра: ведущий управляет воспроизведением, паузой, скоростью и перемоткой; гости следуют той же серии и озвучке.
- Восстановление состояния после разрыва связи, проверка идентификаторов видео, защита от устаревших команд.
- Исправления парсера, загрузки страниц каталога и очистки обработчиков плеера.
- Ограничение Electron IPC и локальных файловых протоколов. Обновление из чужого репозитория отключено.

## Совместный просмотр

Каждый участник самостоятельно получает видео через свой клиент. Через сервер передаются только идентификаторы серии/источника/озвучки и состояние плеера, а не видео, ссылка на видеопоток или токены Anixart.

1. Запустите доступный обоим участникам relay по инструкции [server/README.md](server/README.md).
2. Откройте нужную серию, нажмите кнопку совместного просмотра и укажите адрес сервера.
3. Ведущий создаёт комнату и передаёт приватное приглашение другу. Друг вставляет приглашение в своём клиенте.
4. Гостевой клиент разрешает серию через свой каталог. Если тот же источник/озвучка недоступны, это показывается явно.

Адрес localhost работает только на одном компьютере. Для разных компьютеров нужен доступный WSS-сервер с TLS. Готовый публичный сервер не включён. Приглашение даёт доступ в комнату: не публикуйте его. Выход ведущего закрывает комнату; автоматической передачи управления нет.

## Сборка Windows

Node.js 24, Rust stable, Microsoft C++ Build Tools и WebView2. Клиент больше не включает Electron/Chromium или Node sidecar. WebView2 использует системный runtime; установщик скачивает bootstrapper, если runtime отсутствует.

```sh
npm ci --legacy-peer-deps
npm test
cargo test --manifest-path src-tauri/Cargo.toml --no-default-features --lib --locked
npm run make:windows
```

NSIS-установщик: src-tauri/target/x86_64-pc-windows-msvc/release/bundle/nsis. Workflow Build AnixArtix Tauri сохраняет Windows x64 артефакт после тестов, без автоматической публикации релиза. Режим разработки: npm run desktop:dev (требуется конфигурация локальной разработки Tauri).

Relay остаётся отдельным небольшим Node.js-сервисом и не входит в приложение:

```sh
npm ci --prefix server
npm test --prefix server
```

## Текущий объём переноса

Интерфейс/авторизация, настройки, онлайн-плеер через локальный потоковый Rust-прокси, комнаты просмотра, прямые MP4-загрузки и офлайн-просмотр переносятся на Tauri. Поддерживаемые платформы этого этапа: Windows 10/11 x64; Linux/macOS не заявлены.

HLS-скачивание/склейка пока недоступны: приложение не запускает FFmpeg с непроверенными вложенными URL. Онлайн-HLS обрабатывается отдельно. Discord Rich Presence, системное выключение/сон и автоматическое обновление не включены в текущий перенос; соответствующие настройки явно отключены. Базовые уведомления и трей относятся к нативному host.

## Ограничения и безопасность

- Windows-сборки не подписаны, если владелец отдельно не настроил подпись.
- Реальные входы в Anixart/Shikimori и доступность внешних источников требуют отдельной проверки; модульные тесты не доказывают их работоспособность.
- Секрет OAuth Shikimori больше не встраивается в JavaScript интерфейса. Конфигурация OAuth отсутствует по умолчанию; не распространяйте секреты внутри приложения или .env.
- Не используйте приложение для обхода платного доступа. У каждого участника должен быть самостоятельный разрешённый доступ к контенту.

## Cloudflare backend (разработка)

Новый backend в `cloudflare/`: Durable Objects для комнат, D1 для профилей и OAuth, отдельный браузерный портал. См. [контракты и настройку](cloudflare/auth.md) и [лимиты комнат](cloudflare/rooms.md). Конфигурация пока содержит заглушку ID базы; сервер не считается развёрнутым после одной сборки исходников. OAuth-кнопки включаются только при настоящих настройках провайдеров.

```sh
npm ci --prefix cloudflare
npm test --prefix cloudflare
npm run check --prefix cloudflare
```

Независимый аккаунт AnixArtix в настройках клиента использует системный браузер, одноразовый код и PKCE. Он не заменяет вход Anixart; токены приложения остаются в Rust и могут сохраняться в Windows Credential Manager по выбору пользователя. См. [desktop account](docs/desktop-account.md).
